🏃 Fitness Tracker – Android Application

A simple and user-friendly Android Fitness Tracker application developed using Java and SQLite. The application helps users record daily physical activities, monitor fitness goals, and track their progress through a clean dashboard.

📌 Project Overview

The Fitness Tracker app allows users to manually record their daily fitness activities, including steps, calories burned, and workout duration. It provides daily and weekly summaries to help users monitor their fitness progress.

This project was developed as part of the CodeAlpha Internship Program.

✨ Features

- Activity Tracking: Record activities such as walking, running, and workouts.
- Manual Data Entry: Add workout duration, calories burned, and steps.
- Daily Fitness Dashboard: View daily fitness statistics.
- Daily Fitness Goals: Monitor progress toward daily targets.
- Progress Bars: Visualize goal completion.
- Weekly Summary: Review accumulated fitness statistics.
- Activity History: View recently saved fitness records.
- SQLite Database: Store activity records locally on the device.
- Simple User Interface: Clean and easy-to-use dashboard.

⚙️ Installation and Setup

1. Clone this repository:

git clone https://github.com/YOUR-USERNAME/CodeAlpha_FitnessTracker.git

2. Open Android Studio.

3. Select Open and choose the cloned project folder.

4. Allow Gradle to sync and download the required dependencies.

5. Run the application using an Android emulator or a connected Android device.

🚀 How to Use

1. Launch the Fitness Tracker application.
2. Enter an activity name.
3. Enter workout duration in minutes.
4. Enter calories burned.
5. Enter the number of steps.
6. Tap Save Activity.
7. View updated daily goals, weekly progress, and recent activity history.
